# agent-planner 智能体任务规划（中文版）

任务规划、事实验证、审计工作流，以及 F0-F12 流程的知识库集成。提供带检查点和质量门禁的结构化规划阶段。

🌐 **语言**: [English](README.md) | **简体中文**（当前）

## 描述

为 OpenClaw 框架提供多 agent 任务规划能力，遵循 F0-F12 流程。

### 核心特性

- **F0-F12 阶段化流程**：从需求分析到知识库集成的完整流程
- **F0.5 事实验证**：所有事实性主张必须经过验证
- **审计工作流**：可审计的决策过程
- **知识库集成**：自动从 _knowledge/ 加载相关上下文
- **检查点机制**：每阶段可暂停、恢复
- **质量门禁**：每个阶段都有通过条件

### 适用场景

- 多 agent 团队任务拆解
- 复杂任务规划（F0 → F12）
- 任务审计与回溯
- 知识库驱动的决策

## 安装

将整个 agent-planner/ 目录复制到 OpenClaw 技能目录（通常是 ~/.openclaw-skills/agent-planner/）。

## 目录结构

\agent-planner/
├── SKILL.md          # 技能主定义（先读这个）
├── references/       # 参考文档
├── scripts/          # 可执行工具
├── _knowledge/       # 知识库
└── _meta.json        # 技能元数据
\
